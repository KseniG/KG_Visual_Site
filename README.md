# KG Visual Site

Локальный запуск из корня проекта в терминале VS Code:

```powershell
npm.cmd ci
npm.cmd run dev
```

После первой установки достаточно команды dev. Проверка типов — `npm.cmd run typecheck`, сборка — `npm.cmd run build`. В автономной версии проверяются исходники, кроме неиспользуемого шаблона облачной формы `src/components/wow/form.ts`, которому требуется закрытый модуль Lepka.

## Материалы

Изображения лежат в `public/img`. Портрет — `site-me.webp`, знак для шапки — `kg-logo.svg`. Названия остальных картинок указаны в `src/data/portfolio.ts`. Для замены сохрани имя и формат, либо измени путь в компоненте. Видео воспроизводятся через стандартный плеер браузера.

| Файл в public/video | Кейс |
| --- | --- |
| ossetia.mp4 | Осетия |
| fintech.mp4 | Финтех |
| ustyug.mp4 | Великий Устюг |
| new-year.mp4 | Новогодний шар |

При замене роликов проверь длительность и пропорции в карточках. Локальные пути к медиа учитывают базовый адрес Vite.

## Порядок правок в Lepka

- [ ] В шапке поставить личный знак. Порядок ссылок — «Обо мне», «Кейсы», «Подход», «Контакты».
- [ ] Сохранить содержание разделов. Убрать маленькие надписи «Обо мне», «Подход», строку Author photo и вводное предложение над фотолентой. Исправить «я специалист».
- [ ] Заменить английские названия направлений в карточках, проверить написание «меппинг» в тексте, навигации, контактах и метаописании.
- [ ] Сделать три карточки ссылками. Графика → #graphics, 3D → #mapping-new-year, AI + motion → #motion. Если для 3D важнее предметный дизайн, выбрать другой целевой кейс.
- [ ] Переименовать «Показы» в «Проекты на мероприятиях», ссылки на Telegram подписать «Открыть пост».
- [ ] В блоке цифр убрать фон и рамку у отдельных карточек. Оставить большие цифры, пояснения набрать обычным регистром. Для четырёх лет обозначить контекст, десять инструментов перечислить. Сверить, какие работы входят в 15 коммерческих кейсов.
- [ ] В каждом результате назвать изготовленный материал и собственную роль, затем привести эффект. Для блокнота указать дизайн обложки, чертёж и тираж 8. Для Lindaily — графику и 3D-мокап. Для танцевальной студии — публикацию и две печатные афиши. Уточнить период и публикации, к которым относятся просмотры и реакции фестиваля и студии.
- [ ] Для Осетии указать заставку и время показа отдельно от длительности ролика. Для Устюга — три сцены и длительность отрывка в портфолио. Повторно сверить с финальными MP4.
- [ ] В конце сравнить обе версии на телефоне и компьютере. Проверить три якоря, стрелки кейсов, все четыре видео и контакты.
- [ ] После просмотра отдельно решить вопросы со знаком «?» — активность навигации, разделители и место личной айдентики. При желании заменить портрет исходным фото.

## GitHub Pages

Для публикации создать репозиторий KG_visual_site в нужном аккаунте GitHub, привязать его как origin и отправить main. В Settings → Pages → Build and deployment выбрать GitHub Actions. Если исходники уже отправлены, открыть Actions → Deploy portfolio to GitHub Pages → Run workflow. В дальнейшем достаточно отправить коммит в main.

Workflow получает базовый путь из настроек Pages, выполняет установку из package-lock.json и публикует dist. Адрес опубликованного сайта появится в результате успешного deployment.
